# Security review

Review the requested local changes for security issues. Include staged
changes, unstaged changes, and relevant untracked source files. Use the
optional comment as review guidance. Keep this stage read-only. Use static
inspection. Explain which security control is missing or incorrect and how
to fix it. Omit exploit code, payloads, and reproduction steps.

Report every substantiated finding with a file and line, severity, evidence,
and proposed fix. If you find no issues, say so. Report any part of the
review you could not complete.
